# AI Screen Implementation Guide

## Purpose
This file contains the common rules for implementing any ERP screen in this prototype project.

This project is a **prototype for client pitching**, not a production ERP.
Focus on:
- fast implementation
- polished UI
- simple readable code
- mock-data-driven pages

Do not focus on:
- production architecture
- real backend integration
- advanced optimization
- unnecessary abstractions
