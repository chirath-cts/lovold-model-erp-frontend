# Roadmap and Non-goals

## Phase 1
Current MVP slice includes:
- persisted backend
- modular frontend architecture
- catalog workflows
- customer-specific pricing workflows
- sales workflows
- dashboard workflows

## Phase 2
Planned next:
- supplier onboarding
- procurement flows
- supplier-product terms
- inventory tracking
- warehouse logistics
- stock thresholds and alerts
- order status history
- expanded reporting filters and drill-downs
- richer order workflow states

## Phase 3
Planned hardening:
- authentication and authorization
- API/service hardening
- automated tests
- production-readiness
- deployment concerns

## Known Gaps / Non-goals in Phase 1
- no inventory levels
- no warehouse location management
- no procurement workflows
- no supplier onboarding
- no order audit trail beyond `status`
- no auth/authorization
- no automated test suite yet

## Phase 1 Success Criteria
- stakeholders can validate catalog -> pricing -> order -> profit flow
- UI feels enterprise-ready
- data behavior feels realistic and consistent
- architecture can scale into later phases
- team has a solid baseline for Phase 2 planning
