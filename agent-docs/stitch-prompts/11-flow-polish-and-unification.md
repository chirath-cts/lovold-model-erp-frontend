# Prompt 11: Flow Polish And Unification

Use this after the main sections have been generated.

```md
Continue the Lovold ERP project and review the full set of screens already created.

Now unify the entire product so it feels like one coherent ERP system rather than separate generated pages.

Audit and refine the following across all sections:

- left navigation consistency
- page-header consistency
- summary-card consistency
- table rhythm and spacing
- badge and status consistency
- form layout consistency
- detail-panel consistency
- typography hierarchy
- density and scanability
- risk-state styling
- ETA styling
- inventory-state styling

Then strengthen these cross-screen journeys:

1. Product / Component browsing to order creation
2. Customer pricing visibility into order pricing
3. Order confirmation into reservation and ETA understanding
4. Inbound delay affecting customer order ETA
5. Order progression from draft to delivered
6. Dashboard drill-down into operational screens

Preserve these fixed business truths:

- products and components are different item types
- customer pricing applies only to products
- reserved stock is not available stock
- component pricing includes standard production cost
- ETA is stored and broken into multiple fields
- supplier POs affect order promise timing

Also refine the example content across the product so it feels consistently tied to Lovold's aquaculture engineering domain rather than generic retail, generic SaaS, or unrelated inventory examples.

Refine the full experience so the app feels deliberate, enterprise-ready, and visually coherent across all screens.
```
