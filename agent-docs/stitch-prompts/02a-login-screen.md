# Prompt 02a: Login Screen

Paste this after the app-shell prompt and before the main functional sections.

```md
Continue the Lovold ERP project and preserve the established visual language.

Now design the login screen for Lovold ERP.

This screen should stay simpler than the main product sections, but it should still feel consistent with the same brand, tone, and enterprise quality.

Important constraints:

- This is an internal login screen for Lovold staff.
- It is not a consumer sign-in page.
- Do not turn this into a generic startup SaaS marketing screen.
- Do not add role-management, onboarding, or multi-step auth flows.
- Keep the interaction simple and direct.

The screen should communicate:

- Lovold ERP
- internal operational access
- trust
- engineering reliability
- subtle aquaculture and marine-industrial context

Use domain-relevant visual flavor if imagery or background treatment is included, for example:

- aquaculture infrastructure
- feed barges
- control rooms
- sensor or monitoring hardware
- marine engineering details

Keep the design restrained and professional. Avoid heavy illustration or consumer-style hero marketing.

Design the screen with:

- Lovold ERP branding
- email or username field
- password field
- primary sign-in action
- optional remember-session or keep-me-signed-in control
- optional forgot-password link if useful
- clear error-state design
- loading-state design

If you include supporting text, make it feel appropriate for an internal aquaculture engineering operations platform.

The login screen should feel like the front door to a serious internal ERP product, not a public landing page.
```
