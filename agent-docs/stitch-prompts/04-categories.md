# Prompt 04: Categories

Paste this after Products and Components.

```md
Continue the Lovold ERP project and preserve the existing visual language.

Now design the Categories section as a lightweight classification area.

Business rules:

- Categories apply to both products and components.
- Categories remain lightweight in this phase.
- No hierarchy is needed.
- No category edit or delete expansion is required.

Design the Categories screen with:

- page header
- create category action
- search by name or description
- summary cards
- categories table
- pagination

Important information to show:

- category name
- description
- item count or usage count
- lightweight status treatment if useful

If example categories are needed, use realistic Lovold domain examples such as:

- Feeding Systems
- Mechanical Installations
- Pipe Systems
- Electrical and Control
- Sensors and Monitoring
- Spare Parts
- Service Kits
- Retrofit Packages

This screen should feel simpler than Orders or Inventory, but still consistent with the overall ERP design system. It should read as a utility section that supports catalog organization.
```
