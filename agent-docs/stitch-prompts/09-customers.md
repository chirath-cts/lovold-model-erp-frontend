# Prompt 09: Customers

Paste this after Inbound.

```md
Continue the Lovold ERP project and preserve the same shell and visual language.

Now design the Customers section.

Customer scope remains intentionally lightweight in this phase. This is a commercial visibility area, not a full CRM.

Design these screens:

1. Customers directory screen
2. Customer detail screen

The directory should support:

- search
- filter by status
- filter by region or country
- summary cards
- customers table

Important customer row information:

- customer code
- customer name
- contact details
- region or country
- order count
- revenue
- last order date
- status

Use realistic fictional aquaculture customer examples from regions such as:

- Norway
- Chile
- Scotland
- Iceland
- Canada
- Faroe Islands

Example customer naming can feel like:

- FjordBlue Salmon
- NorthSea Aquaculture
- Arctic Crest Farming
- Highland Cage Operations
- Atlantic Fjord Foods

The customer detail screen should feel like a clean commercial summary page and should show:

- customer summary information
- status
- total orders
- total sales
- estimated profit
- items purchased
- order history

Important business rules:

- customer metrics are derived from orders and order items
- customer scope stays lightweight for now
- create, edit, and delete expansion are not required in this phase

Make this section feel simpler and cleaner than Orders, while still consistent with the overall ERP system.
```
